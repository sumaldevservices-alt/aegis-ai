## 🔥 What is AEGIS?

**AEGIS** is an elite, production-grade sovereign AI infrastructure platform and multi-agent swarm architecture inspired by Nous Research's Hermes Agent. Engineered for zero-downtime autonomy, multi-server fleet management, web intelligence, and self-healing systems, AEGIS bridges cognitive LLM reasoning with deterministic OS execution.

## 📦 60-Second Quick Start & Interactive Wizard

```bash
# Clone the repository
git clone https://github.com/sumaldevservices-alt/aegis-ai.git
cd aegis-ai

# Setup sovereign virtual environment
python3 -m venv venv
source venv/bin/activate

# Install package and dependencies
pip install -e .

# Launch AEGIS (Triggers Interactive Setup Wizard with Rich Animations on first run)
aegis
```

## 💻 Command Reference Guide

| Command | Action | Description |
| :--- | :--- | :--- |
| `aegis` / `aegis init` | Setup Wizard | Calibrate LLM providers, AI models, security policies & Telegram via rich menus |
| `aegis status` | Telemetry | Real-time CPU, virtual memory & disk utilization health check |
| `aegis chat` | Neural REPL | Launch interactive high-effort AI sysadmin conversational shell |
| `aegis run "..."` | Safe Execution | Run shell commands evaluated through the AST safety engine |
| `aegis browse "url"` | Web Intelligence | Extract and parse web pages using the Obscura browser engine |
| `aegis fleet "..."` | Fleet Broadcast | Distribute and execute commands across your server cluster |
| `aegis models` | Model Routing | Inspect neural role assignments and fallback provider profiles |
| `aegis logs` | Audit Trail | Query immutable SQLite WAL security audit logs |
| `aegis memory "..."` | FTS5 Search | Retrieve episodic historical facts and context indexes |
| `aegis schedule` | Cron Daemons | Monitor active automated maintenance tasks |
| `aegis doctor` | Diagnostics | Run comprehensive system integrity checks |
