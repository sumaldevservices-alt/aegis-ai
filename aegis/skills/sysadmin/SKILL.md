# Sysadmin Skill

## Rules
- Always check command risk level before execution (`READ`, `LOW`, `MEDIUM`, `HIGH`).
- Require approval for `MEDIUM` and `HIGH` risk actions unless running in full autonomy mode.
- Log all administrative actions to audit trail.
